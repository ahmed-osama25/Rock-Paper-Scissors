# 🪨 Rock Paper Scissors

A simple **Rock Paper Scissors** game built with **C++** using Object-Oriented Programming (OOP).

## 🎮 Features

- 🪨 Rock
- 📄 Paper
- ✂️ Scissors
- 🤖 Computer opponent with random choices
- 🏆 First player to reach 10 points wins
- 🔄 Play again option
- 📊 Score display
- 🚪 Main menu with:
  - Play
  - Show Score
  - Exit
- ✅ Input validation

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- `rand()` and `srand()` for random computer choices

## 📚 Concepts Practiced

- Classes & Objects
- Private & Public Members
- Functions
- Conditional Statements
- Loops
- `switch`
- Random Numbers
- Boolean Functions
- Input Validation
- Score Management

## ▶️ How to Run

1. Clone the repository.
2. Open the project in your C++ IDE.
3. Compile the source code.
4. Run the program.
5. Choose an option from the main menu.

## 🎯 Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choice = Draw

The first player to reach **10 points** wins the match.
